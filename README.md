# NSE Alpha Pro

## Overview
NSE Alpha Pro is an AI-powered stock scanner for the Indian stock market.

## Features
- Technical Analysis
- Volume & Delivery Analysis
- Minervini Trend Template
- CANSLIM
- VCP Detection
- Sector Rotation
- AI Stock Ranking
- Backtesting
- Daily Swing Trade Report
